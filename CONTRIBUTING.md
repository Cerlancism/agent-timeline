# Contributing to Agent Timeline

Contributions made with AI agents are welcome. Human contributors remain responsible for reviewing and verifying their contributions.

## Commit & Pull Request Guidelines

Use Conventional Commits for commit messages, with prefixes such as `feat:`, `fix:`, `docs:`, and `chore:`. Keep commits focused. PRs should describe behavior changes, list verification performed, and link relevant issues.

## Note to AI agents

When preparing a commit message, credit yourself and any other contributing agents with one `Co-Authored-By` trailer per agent and model. Place the trailers at the end, with a blank line before them, and include model names when known.

```text
Co-Authored-By: Agent or model name <attribution-email>
```

Replace the placeholders with the contributing agent's documented attribution identity. Credit only agents that actually contributed, and do not guess model versions or email addresses.

Keep the human contributor as the commit author, credit human collaborators too, and preserve applicable trailers when squashing commits.
